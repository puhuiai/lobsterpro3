## 第一章：认识龙虾 Pro 3.0

### 1.1 这是什么？

**龙虾 Pro 3.0** 是一套「开箱即用的 AI 全自动运营引擎」。你不需要写任何代码，不需要懂技术，只需要填几个 API Key，就能拥有一个价值 10 万的 AI 员工团队。

### 1.2 能干什么？

|:---------|:-----|
| 📝 自动写文章 | SEO 优化文章、小红书文案、产品描述 |
| 🎨 自动配图 | AI 生成图片、视频、动图 |

| 🛡️ 安全防护 | 风控检测、异常自愈、日志审计 |
| ⏰ 定时任务 | 设置一次，每天自动运行 |

## 第四章：认识你的三大智能员工

你的龙虾引擎内置了 **3 名 AI 员工**，各有分工，配合工作。

### 4.1 🧠 总控员（Commander）

**他是项目经理，负责全盘统筹。**

| 属性 | 说明 |
|:----|:------|
| 能力 | 理解你的需求 → 拆解任务 → 分派给执行员 → 审核结果 |
| 适合说 | "帮我写一篇关于XXX的文章" |
| 不适合说 | "帮我重启一下服务器"（那是技术员的活） |

**典型对话：**
```
你：帮我写一篇宠物猫玩具的推广文章
总控员：收到，我将拆解为以下任务：
  1. 搜索"宠物猫玩具"热销品类关键词
  2. 生成 3 篇不同角度的推广文案
  3. AI 配图（每篇 1 张）
  4. SEO 关键词优化
  已分配 👷 执行员开始处理...
```

### 4.2 👷 执行员（Worker）

**他是一线员工，负责具体干活。**

| 属性 | 说明 |
|:----|:------|
| 能力 | 写文案、生成图片、采集数据、SEO 优化、发布内容 |
| 适合说 | （不需要直接跟他说，总控员会分派） |

**他能做的事：**
- 📝 内容写作 — 文章、文案、产品描述、小红书笔记
- 🎨 AI 生图 — 用即梦 AI 生成配图
- 🔍 数据采集 — 爬取网页、搜索信息
- 📈 SEO 优化 — 关键词布局、标题优化
- 🔄 格式转换 — 文档互转、多语言翻译
- 📢 内容发布 — 自动分发到各平台（需配合 AiToEarn）

### 4.3 🔧 技术员（Technician）

**他是运维工程师，负责系统维护。**

| 属性 | 说明 |
|:----|:------|
| 能力 | 环境维护、故障排查、技能安装、系统自检 |
| 适合说 | "帮我检查一下系统健康状态" |
| 不适合说 | "帮我写一篇文章"（那是执行员的活） |

**他能做的事：**
- 🔍 系统健康检查 — 检测所有组件是否正常
- 🔧 故障修复 — 自动诊断并修复常见问题
- 📦 技能管理 — 启用/禁用技能
- 📋 日志查看 — 查看运行日志和错误记录

### 4.4 他们怎么配合工作？

```
你：帮我的网站写一篇关于"智能猫砂盆"的文章

① 🧠 总控员 收到指令
   ├── 分析需求：需要产品评测类文章
   ├── 拆解任务：搜索素材 → 写文案 → 配图 → SEO优化
   └── 派发给 👷 执行员

② 👷 执行员 开始执行
   ├── 🔍 搜索"智能猫砂盆"相关资料
   ├── 📝 撰写 1000 字评测文章
   ├── 🎨 生成一张产品配图
   └── 📈 进行 SEO 关键词优化

③ 🧠 总控员 审核结果
   ├── 检查文章质量
   ├── 检查配图效果
   └── ✅ 完成！呈现给你
```

## 第九章：常见问题 FAQ

### Q1：安装后打不开控制台？

**可能原因：** Gateway 服务未启动
**解决方法：**
1. 双击桌面快捷方式
2. 或打开 `C:\LobsterPro3.0\gateway.cmd` 手动启动
3. 等待 10 秒，再访问 `http://localhost:18789`

### Q2：提示 API Key 无效？

**解决方法：**
1. 检查 API Key 是否复制完整（注意不要多空格）
2. 检查该 API 是否已充值/有余额
3. 访问各平台重新生成 Key
4. 在控制台 → 系统设置 → API 管理中重新填入

### Q3：技能加载失败？

**解决方法：**
```
控制台 → 系统设置 → 技能管理 → 重新加载
或命令行：
  openclaw skills reload
```

### Q4：任务执行报错怎么办？

1. 查看任务日志（执行员面板 → 任务历史）
2. 日志中会显示具体错误原因
3. 常见的错误：
   - API 余额不足 → 去对应平台充值
   - 网络超时 → 检查网络连接
   - 内容被拦截 → 调整内容措辞

### 10.1 日常维护

**建议每隔一段时间做一次：**
```
打开控制台 → 对技术员说：
"帮我做一次全系统健康检查"
```

### 10.2 手动查看日志

日志文件位于安装目录下的 `logs/` 文件夹：

```
C:\LobsterPro3.0\
├── logs\
│   ├── gateway\
│   │   ├── gateway-2026-05-13.log    # 今日运行日志
│   │   └── gateway-restart.log        # 重启记录
│   ├── tasks\                          # 任务执行日志
│   └── errors\                         # 异常日志
└── ...
```

### 10.3 常见错误处理

| 错误现象 | 可能原因 | 解决方法 |
|:---------|:---------|:---------|
| API 调用返回 401 | API Key 错误或过期 | 重新获取并更新 API Key |
| API 调用返回 429 | 调用频率过高 | 等待 1 分钟再试 |
| 任务卡住不动 | 模型响应超时 | 在技术员面板手动终止该任务 |
| 生图失败 | 即梦 API 配额不足 | 检查火山引擎账户余额 |
| Gateway 无法启动 | 端口 18789 被占用 | 修改端口配置（见 10.4） |
| 磁盘空间不足 | 缓存文件积累 | 在技术员面板执行「清理缓存」 |

### 10.4 修改默认端口

如果 18789 端口被其他程序占用：

```
1. 打开 C:\LobsterPro3.0\openclaw\config.yaml
2. 找到 port: 18789
3. 改为其他端口，如 port: 18888
4. 重启 Gateway
```

### 10.5 清理缓存

```
方法一（推荐）：
  对技术员说："帮我清理一下缓存"

方法二（手动）：
  删除 C:\LobsterPro3.0\workspace\temp\ 下的文件
  注意：不要删除 workspace 下的其他重要文件
```
