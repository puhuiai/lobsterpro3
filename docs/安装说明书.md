   - 步骤：注册火山引擎 → 开通方舟服务 → API Key 管理 → 创建 Key

3. **dq.ai6800 接口地址 + Token**
   - 获取地址：https://dq.ai6800.com
   - 步骤：注册 → 获取 API 地址和 Token

4. **即梦 AI API Key（火山创意）**
   - 获取地址：https://console.volcengine.com
   - 步骤：开通即梦 AI 服务 → API 管理 → 创建 API Key

5. **AiToEarn 授权密钥**
   - 获取地址：https://aitoearn.com
   - 步骤：购买授权 → 获取密钥

**可选（2项）— 增强功能，不影响核心运行：**

6. **5118 API Key**
   - 获取地址：https://5118.com

7. **百度资源平台 Token**
   - 获取地址：https://ziyuan.baidu.com

### 第二章：安装步骤

#### 2.1 运行安装程序
双击 `LobsterPro3.0_Setup.exe`，如出现安全提示请点击「更多信息」→「仍要运行」。

#### 2.2 填写 API 配置
安装向导会显示 API 配置页面：
- 红色标记 * 的为必填项
- 请提前准备好所有 API Key 一次性填入
- 可选配置可留空跳过

#### 2.3 确认安装目录
建议保持默认的 `C:\LobsterPro3.0`，如需修改请使用纯英文路径。

#### 2.4 等待自动安装
安装过程将自动完成以下操作：
1. 解压引擎文件
2. 写入 API 配置到环境变量
3. 注册 Gateway 系统服务
4. 注册 Watchdog 自动重启守护
5. 创建桌面快捷方式
6. 设置开机自启
7. 启动引擎
8. 全链路自检

#### 2.5 验证安装结果
安装完成后：
- ✅ 桌面出现「🦞 龙虾 Pro 3.0」快捷方式
- ✅ 双击打开引擎控制台（http://localhost:18789）
- ✅ 系统托盘显示引擎运行图标
- ✅ 三大智能员工在线
- ✅ 118 个技能全部就绪

### 第三章：首次使用

#### 3.1 打开控制台
双击桌面「🦞 龙虾 Pro 3.0」快捷方式，或浏览器访问 http://localhost:18789

#### 3.2 认识三大智能员工
| 员工 | 名称 | 职责 |
|------|------|------|
| 🧠 Commander | 总控员 | 接收任务、拆解分配、审核结果 |
| 👷 Worker | 执行员 | 内容采集、生成、发布 |
| 🔧 Technician | 技术员 | 环境维护、故障修复 |

#### 3.3 运行第一条任务
在控制台中输入指令，例如：
> "帮我搜索最新 AI 新闻，生成一篇 500 字文章"

总控员会自动拆解任务，分配给执行员，完成后返回结果。

### 第四章：进阶使用

#### 4.1 启用/禁用技能
控制台运行：`openclaw skills enable <技能名>` 或 `openclaw skills disable <技能名>`

#### 4.2 配置定时任务
控制台运行：`openclaw cron add --name "任务名" --schedule "cron表达式" --payload "任务描述"`

#### 4.3 自定义流水线
工作区编辑流水线配置文件，可自定义采集→生成→发布全流程。

#### 4.4 添加更多 API
编辑 `C:\LobsterPro3.0\.env` 文件，添加新的环境变量后重启 Gateway。

### 第五章：维护与故障排除

#### 5.1 常见问题

**Q: 安装后控制台打不开？**
A: 检查系统托盘是否有引擎图标，如无则运行 `C:\LobsterPro3.0\restart-gateway.cmd` 手动启动。

**Q: API 测试连通失败？**
A: 检查 API Key 是否正确，在对应平台确认额度充足。

**Q: 如何重启引擎？**
A: 控制台运行 `openclaw gateway restart`，或运行 `C:\LobsterPro3.0\restart-gateway.cmd`。

**Q: 如何卸载？**
A: 开始菜单 → 龙虾 Pro 3.0 → 卸载，或控制面板卸载程序。

**Q: 如何查看运行日志？**
A: 日志文件位于 `C:\LobsterPro3.0\logs\` 目录。
